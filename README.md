这个文件夹用于2026电赛的视觉准备：

1. 先学习2025年电赛E题视觉部分的开源方案，掌握其中的OpenCV用法和常用函数。
2. 然后在MaixCam2上完成环境搭建与程序运行验证。

## 视觉目标说明

本项目中，目标识别与定位需要围绕“矩形框 60×70”这一尺寸特征进行处理。实际检测流程可概括为：

- 图像预处理
- 图像分割（得到ROI）
- 特征提取
- 识别与检测

## OpenCV流程建议

### 1. 图像预处理
预处理的目的是为了让后续的边缘检测、轮廓提取和识别更稳定。常见步骤如下：

| 步骤 | 说明 | 典型操作 |
| --- | --- | --- |
| 读取图像 | 先获取原始图像数据 | `img = cv2.imread("image.jpg")` |
| 调整大小 | 根据实际分辨率缩放图像 | `cv2.resize()`，可选择 `cv2.INTER_NEAREST` |
| 图像裁切 | 取出感兴趣区域 | `roi = img[100:400, 200:600]` |
| 颜色空间转换 | 将图像转换为便于处理的形式 | `cv2.cvtColor()`，如灰度、BGR/RGB |
| 平滑与去噪 | 降低噪声，便于后续检测 | 高斯滤波 |
| 亮度与对比度调整 | 提升特征可见性 | `cv2.convertScaleAbs()` |
| 二值化 | 将图像转为黑白二值图 | 普通二值化、反向二值化 |
| 形态学处理 | 去除噪点、补洞、增强轮廓 | 腐蚀、膨胀、开闭运算 |

### 2. ROI提取与分割
在图像中先定位出候选区域，再在ROI内进行进一步处理。这样可以减少背景干扰，提高识别速度和准确率。

### 3. 深度处理与特征提取
在ROI区域内进行更细致的处理，例如：

| 处理内容 | 作用 |
| --- | --- |
| 边缘检测 | 提取目标轮廓 |
| 轮廓提取 | 获取目标形状信息 |
| 形状匹配 | 判断是否符合矩形框 60×70 的特征 |
| 颜色/纹理特征分析 | 增强识别鲁棒性 |

### 4. 识别与检测
结合目标的形状、尺寸、颜色和位置等特征进行识别，并输出检测结果。

## **说明**

具体预处理操作需要根据实际拍摄环境、目标物体特性和光照条件灵活调整。不同场景下，可能需要优先使用不同的滤波、阈值和形态学方法。
